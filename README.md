
## Getting Started

This project is a technical assessment.

## How data is handled

- There is a local data directory, inside it a moc_data.dart file.
- this file contains all data viewed inside this app.
- all data is dynamic, meaning tot points and progress percentage and total orders can be changed upon added more or less items.
- user is also dynamic, you can change name phone and other data.

# Important notes

- this project uses extensions for things like SizedBox height and width, padding, sizes. all of which are connected to responsive adapter to manage responsiveness without writing extra line of code.
- all colors and text styles are dynamic.
- all navigation are using extensions for easier implementation.
- clicking on profile which is located on top right side of home screen will navigate you to profile.
- clicking on more details button will also navigate you to profile.
- in profile clicking on leading back button will get you back to home.
- the project is using device preview to check for responsiveness.
